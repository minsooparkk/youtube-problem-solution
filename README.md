# youtube-problem-solution

개인의 질문·고민을 한국어 문제 해결형 유튜브 발표안으로 바꾸는 Codex·Claude Code 공용 스킬입니다.

**본질 문제 추상화 → 해결책 두괄식 제시 → 원칙 → 사례 구체화 → 반론 → 결론**

기본 결과물은 약 10분 발표 원고이며, 기획 요약·시간 구성표·근거 메모를 함께 제공합니다. 길이, 톤, 자막, 원고 또는 개요 형식은 요청에서 변경할 수 있습니다.

## 설치

이 저장소 전체를 아래 폴더 이름으로 배치합니다. `SKILL.md`와 `references/`가 같은 스킬 폴더에 있어야 합니다.

| 도구 | 개인 스킬 경로 |
| --- | --- |
| Codex | `~/.agents/skills/youtube-problem-solution/` |
| Claude Code | `~/.claude/skills/youtube-problem-solution/` |

두 도구에 각각 복사하면 독립 복사본이 됩니다. 업데이트 시 양쪽에 같은 변경을 적용하세요. 스킬이 표시되지 않으면 앱을 다시 시작하세요.

## 사용

Codex:

```text
$youtube-problem-solution
아래 질문으로 10분 유튜브 발표안을 만들어줘.
질문: AI가 발전하는데 세무사 시험에 몇 년을 투자해도 될까요?
```

Claude Code:

```text
/youtube-problem-solution AI가 발전하는데 세무사 시험에 몇 년을 투자해도 될까요? 이 질문으로 10분 발표안을 만들어줘.
```

‘5분으로’, ‘발표자용 개요만’, ‘구간별 자막도 한 문장씩’ 등을 덧붙일 수 있습니다. 질문이 이미 대화에 있으면 다시 붙여 넣지 않아도 됩니다.

- [세무사 진로 예시](references/career-example.md): 문제 추상화 수준을 보여주는 예시
- [설계 근거](references/design-notes.md): OpenAI 공식 가이드 반영 내역과 도구별 스킬 문서

실제 사실과 가상 사례를 구별하며, 최신 사실은 실행 환경에 검색 도구가 있을 때 확인합니다. 낭독 시간은 실측 발표 속도가 없으면 추정치입니다.

6단계 영상 구조는 사용자 기획 방식을 정리한 것으로, OpenAI 공식 영상 제작 프레임워크를 의미하지 않습니다.

# 질문에서 본질 문제를 추상화하는 예시

제공된 ‘세무사 진로 조언’ 대화의 요약이다. 학생의 직접 인용이나 검증된 미래 예측이 아니다.

- 질문 요지: 대학 3학년 학생이 휴학 후 세무사 시험 준비를 고민한다. AI가 발전하면 수년의 공부가 무의미해질까 걱정하며, AI 분야나 1인 창업을 준비해야 할지 궁금해한다.
- 본질 문제: 기술 변화로 투자한 시간의 가치가 불확실할 때, 어떤 기준으로 전문성에 투자할 것인가?
- 두괄식 답변 예시: 현재 가치 있고 다른 경로에도 활용할 수 있는 전문성을, 본인의 적성과 준비 비용을 감당할 수 있는 범위에서 쌓자. 자격 취득 이후에는 실무·AI 활용·고객 이해로 확장하자.
- 원칙 예시: 전문성의 활용 범위, 감당할 수 있는 투자 비용, 진행 중 재평가 가능성을 기준으로 선택한다.
- 사례 방향: 수험생의 학습 계획과 다른 분야 종사자의 역량 투자에 같은 기준을 적용한다. 구체적인 경제 상황이나 학습 역량은 알려져 있지 않으므로 만들지 않는다.
- 반론 방향: 시험 준비의 기회비용과 기술이 예상보다 빠르게 변할 위험에 답한다. 모든 사람에게 수험을 권하지 않는다.
- 결론 방향: 원래 질문자에게 조건부로 직접 답하고, 이번 주 적성·비용·학습 계획을 점검할 행동을 제안한다.

이 예시는 구조를 설명한다. AGI의 도래 시기, 특정 직업의 생존, 자격 취득 후 소득은 단정하지 않는다. 발표자의 실제 상담 경험이나 학생의 학교·이름을 추가하지 않는다.
